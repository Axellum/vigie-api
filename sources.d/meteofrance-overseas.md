| **Météo-France AROME Outre-mer** (`meteofrance_overseas`), the high-resolution model of the overseas territories (0.025 degree, hourly to +48 hours, four runs a day), package `SP1` of `DPPaquetAROME-OM/v1` on `public-api.meteofrance.fr`, read as windows around the islands by the [vigie-meteo](https://github.com/Axellum/vigie-meteo) gateway | **Licence Ouverte 2.0 (Etalab)**, as the licence document of the API on the portal states it (read 2026-11-18): reuse, commercial included, with the source named, the date of the last update given (the run) and the data not altered. | [licence of the API](https://portail-api.meteofrance.fr/api/am/devportal/v3/apis/a048fffe-3c6f-41f6-97c8-35e8fb0cea2b/documents/c887eb90-20fa-44fb-93c1-7d8b42439b86/content), [portal](https://portail-api.meteofrance.fr) | `Source: Météo-France, modèle AROME Outre-mer (https://portail-api.meteofrance.fr, Licence Ouverte 2.0), read by a vigie-meteo gateway, dated by its run; the weather code is worked out by Vigie from the rain and the cloud cover, not a Météo-France product` (wording: ours) | 50 requests a minute on the portal for the key; the gateway makes 245 per run (one file per lead time and territory), every 6 hours, spaced out. This API asks the gateway for a point, cached 15 minutes per cell (a ceiling of our own, 3,000 points every 5 minutes). | Optional: on when `VIGIE_METEO_GATEWAY_URL` is set (`VIGIE_METEO_GATEWAY_OVERSEAS=0` turns it off). For a point in Guadeloupe, Martinique, Saint-Martin, Saint-Barthélemy, French Guiana, La Réunion, Mayotte, New Caledonia, the Society, western Tuamotu and Austral islands, `GET /v1/point` takes the current conditions and the complete local days from the model; the rain probability, the UV maximum, the other days and the hourly cloud cover stay Open-Meteo's. The weather code is ours (rain, then cloud cover). Not covered: the Marquesas, Gambier, Wallis-et-Futuna, Saint-Pierre-et-Miquelon, the TAAF (Open-Meteo as before). |
