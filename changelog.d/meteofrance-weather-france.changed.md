- **Weather of France from the Météo-France models** (optional, with `VIGIE_METEO_GATEWAY_URL`; `VIGIE_METEO_GATEWAY_WEATHER=0` turns it off): for a point in a box around metropolitan France and Corsica, the current conditions, the 15-minute rain and the first four days come from AROME and ARPEGE through the vigie-meteo gateway (pressure and weather code from ARPEGE, which AROME HD alone lacks) instead of Open-Meteo's public API, which keeps the rain probability, the later days and the hourly cloud cover. The UV index comes from Météo-France's PHEALTH model (`meteofrance_uv`, `DPPaquetENVIRONNEMENT`): the maximum of today and tomorrow, and the index of the current hour calculated from it and the height of the Sun. Both sources are credited and listed in `disabled_sources` when off; outside the box, or when the gateway fails, Open-Meteo's public API gives the weather as before (ADR 0028).
