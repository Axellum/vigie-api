- **French drought restrictions from VigiEau (`api.vigieau.gouv.fr`, Licence Ouverte 2.0)**:
  - `GET /v1/drought` returns active drought zones, prefectural decree PDF links, usage restrictions (filterable locally by `water_type` `AEP`/`SUP`/`SOU` and `profile` `particulier`/`entreprise`/`collectivite`/`exploitation`), and per-resource `availability` (`available`, `confirmed_none`, `unavailable`) for a French coordinate (`0.02°` grid cache) or INSEE commune code (`409` `ZONE_LOCATION_AMBIGUOUS` surfaced as `status: "ambiguous_commune"`). Coordinates outside covered French territories (`FR, GP, MQ, GF, RE, YT`) return `outside_coverage` offline with zero upstream requests.
  - `GET /v1/drought/departments` serves departmental maximum drought levels across all 101 French departments from a single cached hourly fetch, filtered locally by `department`, `region`, and `min_level`.
  - `GET /v1/point` embeds an informative `drought` summary block when the coordinate is inside covered French territories without altering `local_alert_level`.
