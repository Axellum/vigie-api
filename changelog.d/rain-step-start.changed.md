- **« Rain in N min » counts from now** (Home Assistant integration 0.8.1): the frame's `ZONE` field 16 (`rain_eta_min`) and the Home Assistant card count the minutes from the time of the frame (or of the card) to the first rainy step that has not ended, and skip a step already over (with Open-Meteo the first one always is). Before, they counted from the first step, so rain in a quarter-hour already over read as « it rains now ». The frame's nowcast (`ZONE` fields 16 to 18, `RAIN5M`) is now empty when the start of the steps is unknown. The nine 5-minute slots of the Home Assistant sensor start at `start_utc`.
