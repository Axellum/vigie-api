- **Surf**: `GET /v1/surf/spots/{id}?correct=true` multiplies the height of the whole sea (`hours[].waves.height_m`) by a factor found against a CANDHIS wave buoy, at the eight spots whose factor met the criterion of the measure (ADR 0023; the model reads about 10 % low there). Off by default (`VIGIE_SURF_CORRECTION=on` makes an instance apply it unless a request says `correct=false`). The model's value stays in `waves_model_height_m`, the new `correction` object says what was done or why not, and nothing else in the answer changes: not the swell, the rating, the best slot, the overview or the activity verdicts. The factor brings the forecast closer to the buoy, which can be 25 km from the spot.
